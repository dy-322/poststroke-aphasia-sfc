# Structural-functional coupling in post-stroke aphasia

This repository contains the analysis code for the manuscript:

**Structural-functional over-coupling in attention and sensorimotor networks tracks aphasia severity and subtype heterogeneity after stroke**

The code is organized around the main non-ML, non-transcriptomic analyses in the paper:

1. PCA-based structural-functional coupling (SFC) calculation.
2. Group and network-level SFC summaries.
3. ROI-wise group comparison, Cohen's d maps, and spin-test enrichment.
4. SFC-language correlation analysis.
5. Lesion-zone, disconnectome, mediation, and asymmetry analyses.

Machine-learning/foundation-model code and gene-expression/PLS code are intentionally not included in this draft folder.

## Data Policy

This repository should contain code only. Do not commit subject-level clinical tables, raw imaging data, lesion masks, SFC output files, or generated figures.

The following inputs are expected to be prepared locally:

- subject-level SC matrices, FC time series, and structural communication matrices;
- subject-level SFC text files generated by the SFC pipeline;
- anonymized clinical score tables;
- lesion masks or ROI-level lesion summaries;
- public atlas resources, including Schaefer-400/Tian-50 labels, ROI centroid coordinates, and MNI atlas images;
- HCP-1065 tract probability templates for disconnectome analyses.

Use `configs/paths.example.yaml` as a template for local paths.

## Typical Analysis Order

### 1. Compute SFC

```bash
python src/compute_sfc/compute_sfc_pca.py \
  --base_data_path /path/to/prepared_subject_dirs \
  --result_dir outputs/sfc_pca_450_t288 \
  --distance_matrix_file /path/to/euclidean_distance_matrix_450.mat \
  --roi_number 450 \
  --n_components 4 \
  --target_real_time 288 \
  --remove_first_n 10
```

Hospital validation inputs can be prepared and run with:

```bash
python src/compute_sfc/prepare_hospital_sfc_inputs.py
python src/compute_sfc/run_hospital_sfc_pca_450.py
```

### 2. Summarize Group SFC Maps

```bash
python src/group_sfc_maps/summarize_sfc_by_group.py
python src/group_sfc_maps/plot_group_surface_maps.py
python src/group_sfc_maps/plot_network_sfc_boxplots.py
```

### 3. Test Group Differences

```bash
python src/group_statistics/roi_group_comparison_cohens_d.py
python src/group_statistics/spin_test_group_rois.py
python src/group_statistics/plot_significant_network_radar.py
python src/group_statistics/plot_cohens_d_network_boxplots.py
```

### 4. Test SFC-Language Associations

```bash
python src/language_correlations/correlate_sfc_language_scores.py
python src/language_correlations/spin_test_language_rois.py
python src/language_correlations/plot_language_network_correlations.py
python src/language_correlations/plot_language_correlation_scatters.py
```

### 5. Lesion and Asymmetry Analyses

```bash
python src/lesion_disconnectome/analyze_lesion_zone_sfc_zscore.py
python src/lesion_disconnectome/disconnectome_mediation.py
python src/lesion_disconnectome/plot_disconnection_sfc_scatter.py
python src/asymmetry/analyze_sfc_asymmetry.py
python src/asymmetry/compute_left_right_ai_correlation.py
```

## Important Notes Before Public Release

This folder is a cleaned code selection from the working analysis directory. Some scripts still contain local absolute paths from the original analysis environment. Before uploading publicly, replace those path constants with either command-line arguments or a shared config loader based on `configs/paths.example.yaml`.

Surface plotting scripts use a local `neurocat` helper in the working environment. For a fully portable public release, either vendor a lightweight version of that helper or replace those calls with a standard `nilearn`/`neuromaps` plotting workflow.
